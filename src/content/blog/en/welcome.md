I built this site to collect my research, publications and technical notes in one place. It is generated with [Astro](https://astro.build), hosted on GitHub Pages and available in Turkish and English.

## What I will share

- Notes on natural language processing and machine learning
- Short summaries of papers I read
- Engineering problems I run into at work, and how I solved them

My older C programming examples live on my [Blogspot](https://corneklerim.blogspot.com) page and other articles on [Medium](https://medium.com/@isakulaksiz.ce). New posts will be published here.

## Adding a post

To add a post, drop a Markdown file into `src/content/blog/en/`:

```md
---
title: "Post title"
description: "Short description shown in the list."
pubDate: 2026-11-01
tags: ["nlp", "python"]
---

Post content…
```
